# Module Setup

`l3io-pm-plan-execution` is part of the `l3io-pm` module, which is configured by `/l3io-pm-sprint-execute`.

To set up the `l3io-pm` module for this project, run:

```
/l3io-pm-sprint-execute setup
```

Once configured, return to `/l3io-pm-plan-execution` to generate your execution plan.
